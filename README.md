# Pharmacy Management System

A Python and SQLite-based Pharmacy / Medicine Management System to manage medicine stocks, sales, and reports.

## Features

- **Medicine Management**: Add, display, search, update, delete, and restock medicines.
- **Sales Management**: Process sales, calculate totals, view sales records, and cancel sales.
- **Reports**: View sales summary, low stock alerts, and expired medicines.
- **Database**: SQLite3 database (`medicine.db`) for persistent storage.

## How to Run

1. Run the application:
   ```bash
   python main.py
   ```
