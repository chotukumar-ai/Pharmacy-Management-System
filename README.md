A Python and SQLite-based Pharmacy Management System designed to simplify medicine inventory management, sales operations, and pharmacy reporting through a menu-driven console interface.

## 📌 About the Project

The Pharmacy Management System is a programming project developed to manage pharmacy-related records in a structured and organized way. It aims to reduce manual record-keeping and make medicine inventory operations easier to handle.

The project uses Python for application logic and SQLite for database storage.

## ✨ Features

- 💊 **Medicine Management:** Add, display, search, update, and delete medicine records.
- 📦 **Stock Management:** Restock medicines and maintain inventory quantities.
- 🛒 **Sales Management:** Manage medicine sales and maintain sales records.
- 📊 **Reports:** View sales summaries and identify low-stock or expired medicines.
- 🗄️ **Database Integration:** Store records persistently using SQLite.
- 🖥️ **Console Interface:** Simple, menu-driven interaction through the terminal.

> **Note:** Features are subject to implementation and testing as development progresses.

## 🚀 Getting Started

### Prerequisites

Make sure you have the following installed:

- Python 3
- Git
- Visual Studio Code (recommended)

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/chotukumar-ai/Pharmacy-Management-System.git
```

**2. Navigate to the project directory**

```bash
cd Pharmacy-Management-System
```

**3. Run the application**

```bash
python main.py
```

If `python` does not work on Windows, try:

```bash
py main.py
```
